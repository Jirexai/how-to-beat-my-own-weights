## Why Should You Care?

Right now, you are probably using AI in one of two ways:

1. **Blindly trusting it** -- shipping outputs without validation, treating the system prompt as a firewall, testing only the happy path.
2. **Blindly distrusting it** -- "AI hallucinates, it's unreliable" and refusing to integrate it into critical workflows.

Both are wrong. The AI is neither trustworthy nor untrustworthy -- it is **governable**. But only if you understand how it actually works.
